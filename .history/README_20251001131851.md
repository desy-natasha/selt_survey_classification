# SELT Text Classification Project 

## About
This repository contains training notebooks and trained models for multi-task, cascaded multi-class, and cascaded multi-label classification using transformer-based architectures (DeBERTa and RoBERTa).

## Models
- **`eda.ipynb`** – Exploration of the dataset. 
- **`deberta_cascaded_multi_class.ipynb`** – Cascaded multi-class classification using DeBERTa.  
- **`deberta_cascaded_multi_label.ipynb`** – Multi-label classification using DeBERTa.  
- **`roberta_cascaded_multi_class.ipynb`** – Cascaded multi-class classification using RoBERTa.  
- **`roberta_cascaded_multi_label.ipynb`** – Cascaded multi-label classification using RoBERTa.  
- **`roberta_multi_task.ipynb`** – Multi-task classification using RoBERTa.  


## Trained Models
Models in the `results_*` folders can be loaded directly for future implementation.
- **`results_cascaded_multi_class`** – Trained RoBERTa model for cascaded multi-class classification.  
- **`results_cascaded_multi_label`** – Trained RoBERTa model for cascaded multi-label classification. 
- **`results_multi_task`** – Trained RoBERTa model for multi-task classification.  


## Dataset Files

- **`synthetic_data_mixed_labels.xlsx`** – Synthetic dataset used for training.  
- **`synthetic_data_test.xlsx`** – Test synthetic dataset for evaluating model performance.

## Notes
All the jupyter notebooks mentioned above will work with other models from the Hugging Face's transformer library as well.

For example, the notebook for the 'roberta' model will also work with the 'deberta' model. It is a matter of changing the model name and making slight modifications in the implementation.

This gives you the flexibility to test the model configuration in both model notebooks and see what works best.
